# MP4 Video Merger Studio (1920x1080 Full HD)
កម្មវិធីភ្ជាប់វីដេអូខ្លីៗកម្រិត Full HD (1920x1080) ដោយប្រើប្រាស់ HTML5 Canvas, Web Audio API និង Gemini AI។

## លក្ខណៈពិសេស (Features)
- 🎬 **Video Merger:** បញ្ចូលវីដេអូជាច្រើនចូលគ្នាតែមួយ រួច Export ជា MP4
- ✨ **Smart Transitions:** ចលនាផ្លាស់ប្តូរវីដេអូ (Fade, Zoom, Blur, Whip Pan, Slide)
- 🎨 **Smart Color Grading:** តម្រងពណ៌ភាពយន្ត និង AI Auto Color Enhance
- 🪄 **Chroma Key Studio:** លុបផ្ទៃបៃតង/ខៀវ និងប្តូរផ្ទៃខាងក្រោយ
- 📢 **Smart Watermark & Banners:** ដាក់អក្សររត់ ផ្សព្វផ្សាយពាណិជ្ជកម្ម និងឡូហ្គោឆានែល
- 🎙️ **AI Audio Transcribe & Translation:** វិភាគសំឡេង បកប្រែ និងបង្កើតសំឡេង AI (Gemini TTS)

## របៀបដំណើរការ (How to Run)
```bash
node server.js
```
បើក Browser ទៅកាន់អាសយដ្ឋាន៖ `http://localhost:3456/`
